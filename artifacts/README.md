# Artefatos de modelagem

Binários, snapshots e modelos não são versionados neste repositório. Para cada execução, registre fora do Git:

- data/hora e autor;
- SHA-256 do snapshot;
- período, horizonte e split;
- versão do código (commit);
- hiperparâmetros e seed;
- MAE, RMSE e métricas de alerta por split;
- caminho do modelo e das previsões.
